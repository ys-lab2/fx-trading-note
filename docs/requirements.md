# FXトレードノートアプリ 要件定義

## 1. 概要
個人用のFXトレードノートアプリ。PC・スマホ両方からアクセスでき、データはクラウド上で自動同期される。

## 2. 利用者
- 本人（1名）のみを想定。
- クラウドにデータを置くため、データ保護目的で簡易的なログイン（メール/パスワード or Googleログイン）を用意する。

## 3. 機能要件（v1）

### ① トレード記録（必須）

**基本項目**
- 日時（エントリー日時・決済日時）
- 通貨ペア、売買方向（買/売）、ロット数
- エントリー価格、決済価格
- 損益（pips・金額）
- 手数料/スワップ（任意）

**リスク管理項目**
- LC target：ロスカット価格（レート値で入力）
- TP target：利確目標価格（レート値で入力）
- R:R（リスクリワード比）：`reward ÷ risk = |TP - エントリー価格| ÷ |エントリー価格 - LC|` で自動計算・自動更新
- MAE（Maximum Adverse Excursion、最大逆行幅、pips）：MT5 CSVインポートから自動取得
- MFE（Maximum Favorable Excursion、最大含み益幅、pips）：MT5 CSVインポートから自動取得
- WIN/LOSE：選択式（損益から初期値を自動セットしつつ、手動で上書き可能）

**入力方法**
- 手入力（フォーム）
- CSVインポート（MT5からエクスポートしたCSV。MAE/MFEを含む形式を想定）
  - MT5サーバー時刻とJSTのズレを補正するため、インポート時に「時差補正（時間）」を設定できるようにする（サマータイムで変動するため固定値ではなく都度調整可能にする）
  - ⚠️ MT5標準の取引履歴レポートにはMAE/MFE列が含まれないため、EA/スクリプトでログ出力したCSV、または特定のプラグイン出力を想定。実際のCSVサンプル（ヘッダー行のみでも可）を入手後、カラムマッピングを確定する
- ボタンクリックで現在レートを自動入力（無料FXレートAPIを使用。TradingViewは参考チャート表示のみ埋め込み、値の自動取得は行わない）

**添付**
- スクリーンショット画像添付（v1から対応。アップロード前にクライアント側で圧縮し、ストレージ容量を節約）

**分類・振り返り**
- タグ付け（手法、感情、ルール順守度など自由に設定可能）
- 自由記述の振り返りメモ

### ② 統計ダッシュボード
- 勝率、プロフィットファクター、平均損益、資産推移グラフなど

### ③ カレンダー表示
- 日別/月別の損益をカレンダー形式で表示

## 4. 非機能要件
- PC・スマホ両対応（PWA、レスポンシブデザイン）
- クラウド自動同期
- オフライン対応：v1では不要
- 無料〜低コスト運用を目指す

## 5. 将来検討事項（v2以降）
- 複数ユーザー対応への拡張
- 各社CSVフォーマットへの本格対応
- オフラインキャッシュ対応
- 経済指標カレンダー連携
- MAE/MFEの自動計測（価格ティック監視による将来的な自動化）

## 6. 技術構成（提案）

| 領域 | 選定 | 理由 |
|---|---|---|
| フロントエンド | Next.js (React) + TypeScript | PWA化しやすく、Vercelとの相性が良い |
| PWA化 | next-pwa / Serwist | ホーム画面追加・アプリライクな見た目を実現 |
| UI | Tailwind CSS + shadcn/ui | 実装が速く、レスポンシブ対応も容易 |
| グラフ | Recharts | ダッシュボードのグラフ描画 |
| バックエンド | Supabase (Postgres + Auth + Storage) | 無料枠が手厚く、認証・DB・画像ストレージが一体型でクラウド同期の要件に直結 |
| レート取得 | 無料FXレートAPI（例: exchangerate.host, Frankfurter等を候補に精査） | ボタンクリックでの自動入力用 |
| チャート表示 | TradingViewウィジェット（埋め込み・参照用） | 値の自動取得はできないため視覚確認用途に限定 |
| ホスティング | Vercel | Next.jsと親和性が高く無料枠で運用可能 |

### ラフなデータモデル
- `trades`: id, user_id, opened_at, closed_at, pair, side, lot_size, entry_price, exit_price, pnl_pips, pnl_amount, fee, swap, lc_target, tp_target, risk_reward, mae_pips, mfe_pips, result(WIN/LOSE), memo, screenshot_url, created_at
- `tags`: id, user_id, name, category（手法/感情/ルール等）
- `trade_tags`: trade_id, tag_id（多対多の中間テーブル）

### 無料枠の注意点
- Supabase無料枠：DB 500MB、Storage 1GB程度。個人利用なら十分だが、画像は圧縮必須
- Vercel無料枠：個人開発規模なら十分
